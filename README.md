# What is KIIEX?

### Overview

KIIEX is an on-chain FX desk that powers global payments, trading, and finance solutions in an easy-to-use platform designed for everyone. Users, businesses, and builders can use KIIEX by signing up for an account or connecting via APIs.

Unlike traditional platforms, KIIEX uses a **hybrid approach** to source liquidity and maintain balances on-chain, with exposure to local currencies. It supports fiat swaps and pay-ins/payouts through the pricing of local, non-USD stablecoins and other tokenized real-world assets.

---

### Hybrid Matching Engine

At the core of KIIEX is a **hybrid matching engine** that can source on-chain liquidity across any blockchain ecosystem, while using centralized pricing to hedge and rebalance on-chain positions.  
This creates an ultra-liquid layer that can operate 24/7 on certain pairs, even if those pairs only have liquidity during traditional business hours.

---

### Ramps

KIIEX offers a full suite of on-ramps and off-ramps for instant pay-ins and payouts.  
These ramps are available through both the UI and APIs, with the ability to disperse funds directly or to third-party accounts — all while remaining 100% compliant.

KIIEX has developed a suite of APIs that combine centralized and decentralized functionalities into a single integration point.  
Any application can use these APIs to access KIIEX features. For more information, visit:  
- [KIIEX APIs](https://docs.kiiglobal.io/docs/connect-to-kiiex/connect-to-kiiex-apis)

### Compliance (KYC / AML)

KIIEX is fully compliant within each jurisdiction in which it operates. All users must adhere to **Know Your Customer (KYC)** and **Anti-Money Laundering (AML)** standards and requirements.
